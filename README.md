# 🚀 AWS EKS Terraform Platform

A production-style Infrastructure as Code (IaC) project demonstrating how to provision and manage AWS infrastructure using Terraform with a modular architecture.

## Technologies

- Terraform
- AWS
- Amazon EKS
- IAM
- VPC
- Kubernetes
- Helm
- GitHub Actions
- DevOps
- SRE
